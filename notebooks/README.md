# Notebooks

Thin Colab wrappers. All logic lives in the `shipdoc` package; a notebook only mounts Drive, clones
this repository at a pinned commit, installs from `uv.lock`, and shells out to `python -m shipdoc`.
The notebooks are generated by the builders `scripts/colab_build_*.py` (outputs cleared); edit the
builder, not the JSON.

## Production path (the submitted system, v1.5)

| Notebook | Runtime | What it does |
|---|---|---|
| `02n_zeroshot500_native.ipynb` | T4 | zero-shot run over the 500 labelled documents at the native resolution: smoke gate, batch-size bench, resumable run. It stores the batch size the test run must reuse |
| `04c_predict_test_native.ipynb` | T4 | the 200 test documents: smoke gate, run at the 02n batch size, determinism pass, OCR stage, rules R1 to R3, validated assembly. `MODEL = "zs"` is v1.5 (default); `MODEL = "ft"` is the fine-tuned path and is used only if v2 ships |
| `public_smoke.ipynb` | T4 | about 15 to 20 minutes: public clone without a token, pin assertion, install, 5-document smoke gate, banner. It reproduces nothing; it checks that the repository runs |

## Evaluation (the fine-tuning evidence)

| Notebook | Runtime | What it does |
|---|---|---|
| `03n_finetune_native.ipynb` | L4 | LoRA fine-tune at the native resolution; `STAGE` is `smoke`, `fold0`, `fold1`, `fold2` or `final` |
| `05n_oof_infer_native.ipynb` | T4 | out-of-fold inference of a fold adapter and the paired comparison with zero-shot (`FOLD` is 0, 1 or 2) |
| `08_dev_final.ipynb` | T4 | the final adapter on the 100 dev documents at the native resolution (seen layouts) |

## Pins, inputs, secrets

- **Pin.** Every notebook above sets `PINNED_SHA` to the same commit of this repository and asserts
  `HEAD == PINNED_SHA` after cloning (the repository is public: no token, no secret). The pin is the
  first commit of this repository (the code); the second commit changes only the notebooks, the
  file `configs/public_notebooks.json` and the README so that they name that pin. A placeholder
  (`FILL_PINNED_SHA`) makes the first cell of every notebook raise.
- **Re-pinning yourself.** `scripts/colab_build_notebook.py` reads `configs/public_notebooks.json`
  (`repo_url`, `pinned_sha`); change it, run `uv run python scripts/colab_build_zs_native.py` and the
  other `scripts/colab_build_*_native.py`, `scripts/colab_build_public_smoke.py`, and commit.
- **Inputs.** `data.zip` and `assignment.zip` (the evaluators' package, not included here) in
  `MyDrive/shipdoc-extract/`. No account check is made. Only `public_smoke` and the notebooks that
  read images need them; `04c` needs no OCR zip (it runs the OCR stage itself).
- **Parameters.** Every default already holds the right value (the sha7 in run folder names is the
  pin's). Edit `STAGE` (03n), `FOLD` (05n) or `MODEL` (04c) only.
- **Weights & Biases.** Off by default (`USE_WANDB = False`) except in the fold and final stages of
  `03n`, where a missing `WANDB_API_KEY` Colab secret only prints one line and the run goes on
  without it. Logging needs your own key and your own project.

`DEVELOPMENT_NOTES.md` is the long per-notebook design note of the private development workflow.
